<Audience>Administrators</Audience>

Admins can:

- Confirm new instruments
- Check that each instrument’s watcher is running
- Issue and revoke tokens
- Choose who else is an admin
- Roll out new watcher versions
- Connect Linear and Slack
- Delete any run comment
- Review the feedback people send about Data Hub

These pages under **Settings** are for admins only, and members don’t see them in the settings menu:

- **Feedback**: every feedback report people have sent
- **Integrations**: the connections to Linear and Slack
- **Watchers**: the form for rolling out watcher versions, and a list of every watcher
- **Members**: who is an admin

Each instrument also has its own watcher page, under the instrument, and members can read it.

[Security and permissions](/docs/security) explains roles and scopes. Lab operators set up instruments by following [Set up an instrument](/docs/set-up-an-instrument).
