<Audience>Everyone</Audience>

A lab notebook in Data Hub stands for one notebook page, such as the Notion or Google Docs page where an experiment is written up. Adding runs to it gathers them in one place, from every instrument, and lets whoever analyzes a run open the page that explains how the experiment was set up. A run can be in several lab notebooks.

## Add runs to a lab notebook [#add-runs]

On a run page, choose **Add to lab notebook** in the **Lab Notebooks** section. Then do one of these:

- Type a lab notebook’s name to pick one Data Hub already has
- Paste the notebook page’s link. If no lab notebook has that page yet, Data Hub creates one. Give it a name, which starts out filled in from the link, such as a Notion page’s title

In the same window, leave **Make me the owner** ticked to own a lab notebook you create this way. Tick **I ran this run** to claim the run at the same time.

The **Lab Notebooks** section of the run page lists each lab notebook the run is in, with who added it. Select a lab notebook’s name to open [its page in Data Hub](#notebook-page), or the arrow beside it to open the notebook page. Its **⋯** menu copies the notebook page’s link or removes the run from the lab notebook.

To add many runs at once, select them in a runs list and choose **Add to lab notebook** in the action bar; see [Act on several runs at once](/docs/browse-runs#bulk-actions).

### Rules for lab notebooks [#lab-notebook-rules]

- A run can be in up to 20 lab notebooks.
- Each notebook page has one lab notebook, with one name that every run in it shares.
- Two links count as the same page when they differ only in `http` or `https`, `www.`, a trailing slash, the part after `#`, or tracking parameters such as `utm_source`.
- Notion links count as the same page when they have the same page ID, so a link copied before the page was renamed still finds its lab notebook.
- Anyone signed in can create lab notebooks and add runs to them or remove runs from them.
- A deleted run stays in its lab notebooks. You can’t add it to a lab notebook or remove it from one until the run is restored.
- A deleted lab notebook keeps its runs, and restoring it brings them back. Pasting a deleted lab notebook’s link offers to restore it.

## Find runs by lab notebook [#find-runs]

Runs tables show each run’s first lab notebook in the **Lab Notebook** column, with **+1**, **+2**, and so on when there are more. The column header filters the list:

- **In any lab notebook** or **In no lab notebook**. Use **In no lab notebook** to find runs that still need one
- One lab notebook, to see only its runs. Each lab notebook in the menu shows how many of the listed runs it holds, and the menu’s search box narrows the list

Global search (**⌘&nbsp;K** or **Ctrl&nbsp;K**) also finds lab notebooks by name, description, or link. Paste a notebook page’s URL to find its lab notebook, even when your copy of the link differs from the saved one.

## A lab notebook’s page [#notebook-page]

Each lab notebook has a page in Data Hub that lists its runs from every instrument. To open it, do one of these:

- Select a lab notebook’s name anywhere in Data Hub
- Choose it under **Lab Notebooks** in the sidebar, which lists the lab notebooks you opened last and the ones that most recently got a run
- Choose **View all** under **Lab Notebooks** to list every lab notebook, with its owner, run count, instruments, and newest run. Search that list by name, or paste a notebook page’s link to find its lab notebook

To create a lab notebook before it has any runs, choose **New lab notebook** on that list.

The page shows the lab notebook’s description and owner above its runs, which you can search, filter, and act on like any runs table. **Open lab notebook** opens the notebook page. To take runs out, select them and choose **Remove from this lab notebook**.

The **⋯** menu on the page has three actions:

- **Edit details**: change the lab notebook’s name, description, owner, or link. The name is shared by every run in it, and the link can’t point to a notebook page that another lab notebook already has
- **Copy page link**: copy the address of the Data Hub page. Paste it into the notebook page, so each page links to the other
- **Delete**: take the lab notebook off its runs and out of lists and search. The page stays, with **Restore**, which brings the lab notebook back with all of its runs

## From scripts and AI assistants [#lab-notebook-api]

Scripts manage lab notebooks through the [REST API](/docs/api)’s `/lab-notebooks` endpoints:

- Listing and reading lab notebooks needs the `runs:read` scope
- Creating, editing, deleting, and restoring lab notebooks, and adding or removing their runs, needs `lab-notebooks:write`
- A token that registered a watcher can add or remove only its own instrument’s runs, and can’t create, edit, delete, or restore lab notebooks

The run lists take `has_lab_notebook` to list runs in any lab notebook or in none, and `lab_notebook_id` to list one lab notebook’s runs. Each run in a response lists its `lab_notebooks`.

An AI assistant connected to the [MCP server](/docs/mcp) can do the same with the lab notebook tools in the [tools catalog](/docs/mcp/tools). Its `search_runs` tool filters by lab notebook with `hasLabNotebook` and `labNotebookId`.
