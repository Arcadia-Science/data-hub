<Audience>Developers and integrators</Audience>

Every tool returns JSON in a single text content block. When a tool fails, it sets `isError: true` and returns a plain-text message. Each tool below lists its annotations (`readOnly`, `idempotent`, `destructive`) and the schema of its JSON response.

Connecting needs the `read` scope. Every tool without a `readOnly` annotation also needs `write`. See [MCP overview](/docs/mcp) for sign-in and client setup.
