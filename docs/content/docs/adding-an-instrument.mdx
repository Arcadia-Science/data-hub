This guide walks through the end-to-end process of adding a new lab instrument to Data Hub: creating the instrument, installing a watcher, and starting to upload runs.

## Prerequisites

- A personal access token (see [Managing tokens](/docs/managing-tokens)).
- Access to the instrument PC where files are generated.
- Python >= 3.12 and [uv](https://docs.astral.sh/uv/) installed on the instrument PC.

## Step 1: Install the watcher on the instrument PC

Follow the [Installing a watcher](/docs/installing-a-watcher) guide. During `data-hub-watcher init`, choose "Register a new instrument" and provide:

- **Instrument ID** — a kebab-case identifier (e.g., `bio-rad-cfx96`). This becomes the storage key prefix and the permanent identifier across the system.
- **Display name** — a human-readable name (e.g., "Bio-Rad CFX96"). Defaults to a title-cased version of the ID.

The instrument is created with status `pending`.

## Step 2: Activate the instrument

An admin must confirm the instrument before the watcher can start uploading.

1. Open the Data Hub web app.
2. Navigate to the **Instruments** page.
3. Find the new instrument — it will have a yellow `pending` badge.
4. Click the **Confirm** button next to it.

The instrument status changes to `active` and the watcher can now run.

## Step 3: Start watching

On the instrument PC:

```sh
data-hub-watcher watch
```

The watcher will detect new files, group them into runs, upload them, and report everything to the API. Files become viewable in the web dashboard immediately after upload.

## What you get

Once the instrument is active and the watcher is running, you get a fully functional instrument in Data Hub:

- The watcher uploads raw files to cloud storage.
- Runs and files appear in the web dashboard.
- Files are downloadable via pre-signed URLs.
- Watcher health monitoring (heartbeats, events) works in the dashboard.
- Slack notifications fire whenever a new run is created.

<Callout type="info">
Some instruments also support automated preprocessing (metadata extraction, image processing, and similar) that runs server-side as files arrive. Adding a new processor requires changes to the Data Hub codebase and is documented for developers in the [project repository](https://github.com/Arcadia-Science/data-hub/blob/main/developer-docs/guides/adding-an-instrument.md).
</Callout>
