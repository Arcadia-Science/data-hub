Data Hub is a platform for automatically ingesting, processing, and visualizing
data from laboratory instruments. A lightweight **watcher** agent runs on each
instrument PC, uploads new files as they appear, and reports run data to the
Data Hub web app and REST API.

## How it works

1. The watcher monitors a directory on the instrument PC for new files matching
   your configured patterns.
2. New files are grouped into runs and uploaded to cloud storage.
3. The web app and REST API make runs, files, and watcher health available in a
   dashboard, with optional automated preprocessing for supported instruments.
