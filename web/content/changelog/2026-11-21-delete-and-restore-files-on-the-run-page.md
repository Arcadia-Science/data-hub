---
title: Delete and restore files from the run page
docs: https://datahub.arcadiascience.com/docs/browse-runs#delete-files
---

You can now delete a file from a run, for example a duplicate upload that stops your analysis from reading the run. Select files and choose **Delete** in the bar, or open a file and choose **Delete**. When you delete a raw file, Data Hub offers to delete its videos, preview images, and `run.json` too. A message with **Undo** stays for 10 seconds.

Deleted files are left out of the run's file list, downloads, and API lists, but they stay in storage. **Show deleted files** under **Add filter** lists them, hovering over **Deleted** says who deleted a file and when, and **Restore** brings files back.

The file window now shows images, MP4 videos, and PDFs, and lists the files linked to the open file. The run's **Delete** button now reads **Delete run**, and **Dismiss** is now **Delete**.
