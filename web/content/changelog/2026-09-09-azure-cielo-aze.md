---
title: Azure Cielo .AZE project files now process
---

Data Hub now reads melting curves from the Azure Cielo’s `.AZE` project files and shows them in the **Melting Curves** section. Melting temperatures match the CSV export, but other values can differ, because `.AZE` files store raw fluorescence.

The watcher uploads `.AZE` files only after an admin adds `*.AZE` to the instrument’s file patterns.
