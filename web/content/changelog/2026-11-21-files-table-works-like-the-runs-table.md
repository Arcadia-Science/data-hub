---
title: The files table on a run page works like the runs table
docs: https://datahub.arcadiascience.com/docs/browse-runs#filter-files
---

Rows have no buttons now. Select files, and **Upload**, **Download**, **Reprocess**, and **Dismiss** appear in a bar at the bottom of the window. Sort from the column headings; raw and processed files sort together. **Add filter** holds type, status, and **Show deleted files**. Select any row to open that file, and use the arrows to step through the page.
