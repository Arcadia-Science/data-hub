---
title: Deleting runs keeps the window open and shows the reason when it fails
---

When Delete fails for every selected run, the confirmation window now stays open and shows the reason Data Hub gave, so you can try again. It used to close with a general "Failed to delete" message. If only some runs fail, the window still closes and says how many were deleted and how many failed.

The Delete button on a run page now uses the same window as the run list, so the two work the same way, and closing it with Cancel or Escape returns keyboard focus to the button.
