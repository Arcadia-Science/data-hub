---
title: AI assistants can answer questions about Data Hub from its docs
docs: https://datahub.arcadiascience.com/docs/mcp
---

An AI assistant connected to Data Hub can now look things up in Data Hub's documentation and in this changelog, then answer from what it finds. Ask it how to create a token, what a run status means, or what changed recently. It links the page it used, so you can read more.

The answers come from the docs that ship with your deployment, so they match the version you run. If the docs don't cover your question, the assistant says so and offers to send feedback about the gap. It shows you the draft first.
