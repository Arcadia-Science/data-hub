---
title: Run pages stop checking for file updates after five minutes
---

While files are uploading or processing, a run page checks for updates every 5 seconds for up to 5 minutes. Then it stops and shows **Stopped checking for file updates** with a **Refresh** button. Choose **Refresh** to check for another 5 minutes. Uploading or reprocessing files from the page also starts a new 5 minutes.

Before, an open run page checked every 3 seconds until every file finished, even if that took hours.
