---
title: Filter runs by lab notebook label
docs: https://datahub.arcadiascience.com/docs/browse-runs#narrow-a-long-run-list
---

The **Lab Notebook** column's filter now lists the labels of the lab notebook links in the table, with how many runs have each one. Pick a label to see only the runs with that link. Type in the menu's search box to narrow the list, or choose **Labels containing “…”** to see every run whose link label contains what you typed. **Has a link** and **No link** still work as before.

A filtered column header in a runs table is now tinted blue, so you can tell at a glance which columns are filtering the list.
