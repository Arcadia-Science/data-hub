---
title: Preview CSV, JSON, and other text files without downloading them
docs: https://datahub.arcadiascience.com/docs/browse-runs#download-files
---

The files table on a run page now has an eye icon next to the download icon for CSV, TSV, JSON, and other text files. Select it to read the file in a window on the page. CSV and TSV files show as a table, and JSON is formatted so it is easier to read. Large files show their first 1 MB, and the window says so.

Use Previous and Next in the window to move through the other previewable files on the same page of the table.
