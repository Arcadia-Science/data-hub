---
title: Signing in now returns you to the page you opened
---

If you open a Data Hub link while signed out, such as a run page with filters or a tab selected, signing in now takes you back to that page with the same filters. Before, you landed on the home page, or on the top of the Settings section for any Settings page.

Only addresses on Data Hub are used. A sign-in link that points anywhere else sends you to the home page.
