---
title: Watched folders, clickable run metadata, and more
---

- Instrument pages show the folder the watcher reads from and the file patterns it picks up, such as `*.csv`. Hover over either one for an explanation. Files saved anywhere else, or with names that don't match a pattern, won't appear in Data Hub.
- The watcher status badge now sits next to the instrument name. The run count and the computer name no longer appear on the line below it.
- Hovering over an **Offline** badge explains that the watcher checks in once a minute, so a watcher that was just restarted can take up to a minute to show as online.
- The instruments table shows the same file patterns explanation. Its row menu now includes **View watcher**, and **Edit** is now called **Edit details**.
- On a run page, click a metadata tag, such as an experiment type, wavelength, or temperature, to open the instrument's runs table filtered to that value.
- Runs tables no longer show upload, download, reprocess, and delete buttons when you hover over a row. Check the box next to one or more runs and use the bar at the bottom of the page instead.
- Recent comments on the home page and profile pages show how long ago each comment was written, such as "3 days ago".
- **Settings → Watchers** lists a new watcher release as soon as it's published.
- AI assistants connected to Data Hub get an instrument's watched folder when they look it up.
- The sign-in page links to the source code on GitHub.
