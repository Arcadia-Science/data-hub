---
title: AI assistants can show interactive run reports
docs: https://datahub.arcadiascience.com/docs/mcp
---

Some AI assistants now show the same interactive run report as the web app. They need to support MCP Apps, an extension of the Model Context Protocol. The report includes image carousels, plate maps, and the Aunty plate with its well charts. Other assistants still describe the report in text.

In the web app, every plate map now uses the full width of its card.
