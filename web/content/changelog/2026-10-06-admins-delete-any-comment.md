---
title: Admins can delete any run comment
---

Workspace admins can now delete any comment on a run, not only their own. On the run page, the **Delete** action appears on every comment for admins. An admin can also ask an AI assistant connected to Data Hub to delete a comment. Assistants have no Delete button, so they use their delete tool instead.

Editing is unchanged: only the author can edit a comment, and an API token can edit only the comments it posted.
